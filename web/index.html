Where Can This Research Platform Be Hosted Online?

This platform is designed as an ultra-fast, zero-dependency static application powered by pre-compiled daily SQLite analytics. Here is a complete architectural evaluation of the best hosting environments:

TOP RECOMMENDATION (100% FREE)

1. GitHub Pages + GitHub Actions

Cost: $0 / month • Type: Global CDN • Automation: Built-in Cron

The existing repository already has an automated workflow at .github/workflows/daily_update.yml that runs every weekday at 18:00 UTC (23:30 IST).

  • Zero Server Maintenance: GitHub automatically hosts the static web/ files at https://<username>.github.io/MututalFundResearch/.
  • Automated Daily Refresh: The GitHub Action fetches AMFI daily NAVs, runs the calculations, writes the updated web/data/funds.json and Excel workbook, and commits back to the repo.
  • Custom Domains & HTTPS: Supports free SSL and custom domain mapping (e.g., research.yourdomain.com).
Quick Deployment Command:
git push origin main & enable GitHub Pages under Repo Settings > Pages > Source: main / web/.
FASTEST GLOBAL EDGE

2. Cloudflare Pages

Cost: Free Tier • Speed: Sub-20ms Edge • Bandwidth: Unlimited

Connect your GitHub repository to Cloudflare Pages with build directory set to web. Every time GitHub Actions commits new daily NAV data, Cloudflare deploys the changes globally across 300+ edge data centers in seconds.

EASIEST DEV EXPERIENCE

3. Vercel or Netlify

Cost: Free Tier • Features: Preview Branches

Simply import the repository or drag-and-drop the web/ directory. Instant deployment with automatic SSL, Brotli compression, and immutable cache invalidation.

DYNAMIC PYTHON BACKEND

4. Render, Railway, or Linux VPS

Cost: $0–$7 / month • Type: Dedicated Python Service

If you want live on-demand calculation APIs or user accounts, you can run python3 web/server.py directly on a Render Web Service or $5/month Hetzner/DigitalOcean VPS with systemd and Caddy/Nginx reverse proxy.

3. CAPM & Capture Ratio Formulas

  • Beta (β): Covariance of fund daily returns with category benchmark / Variance of benchmark.
  • Jensen's Alpha (α): Annualized excess return over CAPM expectations using India 10Y G-Sec yield (Rf = 7.0%):
    Alpha = CAGR_fund - [Rf + Beta * (CAGR_benchmark - Rf)]
  • Morningstar Monthly Capture Ratios: Compounded monthly returns during positive months (Upside Capture) and negative months (Downside Capture). An Overall Capture Ratio > 1.0 proves superior upside participation with downside defense.
